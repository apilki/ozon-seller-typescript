# Changelog

## 0.3.0 — 2026-11-09

**Первый публичный выпуск клиента Ozon Seller API.**

### Добавлено
- 25 классов API Ozon Seller: аналитика, товары, цены, заказы и отправления (FBS, FBO, FBP), склады, поставки, отчёты, финансы, чаты, отзывы и продвижение.
- TypeScript-типы всех операций и моделей; сборки CommonJS (`dist/`) и ESM (`dist/esm/`).
- Запросы с авторизацией по заголовкам `Client-Id` и `Api-Key`, общий слой ошибок и ограничения частоты запросов к API.
